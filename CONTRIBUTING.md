# Как внести вклад

Сначала прочитайте README. Для крупного изменения откройте issue и согласуйте направление. Небольшие исправления и новые вопросы можно сразу предложить через pull request. Будьте доброжелательны, обсуждайте изменения, а не личности, не публикуйте чужие персональные данные.

## Вопросы

Исходники наборов — `questions/ru.json` и `questions/en.json`. Формальная схема — `questions/schema.json`. Встроенные переводы должны иметь одинаковые ID и порядок. Добавляйте перевод вместе с вопросом.

```json
{
  "id": "licenses-mit-notice",
  "topic": "licenses",
  "difficulty": 1,
  "question": "Что нужно сохранить при распространении копий MIT-кода?",
  "answers": ["Уведомление об авторских правах и текст разрешения", "Только имя файла"],
  "correct": 0,
  "explanation": "MIT требует включать уведомление об авторских правах и текст разрешения в копии или существенные части ПО.",
  "source": "https://opensource.org/license/mit"
}
```

- У каждого вопроса **обязательны `explanation` и `source`**. Ссылайтесь на первоисточники: текст лицензии, официальную документацию, архив проекта.
- `id` уникален в наборе. `topic`: `basics`, `dpg`, `community`, `github` (пользовательские наборы допускают другие темы).
- `difficulty`: 1 — основы, 2 — применение, 3 — нюансы.
- От 2 до 4 разных вариантов, ровно один верный. `correct` — индекс с нуля.
- Формулировка должна быть однозначной; не превращайте сложный юридический случай в безусловное правило. Не копируйте длинные фрагменты документации.
- До 500 вопросов, до 2 МБ в загружаемом наборе. Нельзя использовать HTML вместо текста; ссылки только HTTP(S).

После редактирования:

```sh
python3 scripts/bundle-data.py
python3 -m venv .venv
.venv/bin/pip install jsonschema==4.23.0
.venv/bin/python scripts/validate-questions.py
node --test tests/*.test.cjs
```

`js/bundled-data.js` генерируется из JSON: вручную его не редактируют. GitHub Action проверяет схему, индексы, ID, переводы, актуальность копии и тесты. Для изменения кода проверьте мышь, touch, клавиатуру, оба языка, обе темы, 360px и режим reduced motion. В PR опишите изменение и выполненные проверки.
